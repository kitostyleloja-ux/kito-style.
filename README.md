# Kito Style — protótipo inicial
Abra `index.html` no navegador para visualizar.

## Nesta versão
- Tela de entrada com cliente e acesso ADM
- Catálogo e filtros por categoria
- Carrinho básico
- Cadastro e remoção de produtos no protótipo

## Antes de publicar
Esta é uma demonstração local, NÃO é segurança real nem armazenamento persistente.
O acesso ADM e os produtos devem ser ligados a Supabase Auth, banco de dados, Storage e regras RLS.
Configure o WhatsApp da loja antes de ativar pedidos.
